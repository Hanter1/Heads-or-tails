# Орел или Решка

[![Maintainability](https://api.codeclimate.com/v1/badges/edc1f7c6b272d79b3f55/maintainability)](https://codeclimate.com/github/Hanter1/Heads-or-tails/maintainability)

Данная игра это простая тренировка ООП. 
Из первоначальных задач было написать простую игру Орел или Решка.

Входные данные: 
- 2 пользователя
- у каждого поользователя по 100 монет.

Необходимо найти:
- Победителя
- кол-во подбрасываний
- Шанс на победу 1-го или 2-го пользователя если кол-во монет изменится
